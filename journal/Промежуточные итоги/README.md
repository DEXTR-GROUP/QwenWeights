# ПРОМЕЖУТОЧНЫЕ ИТОГИ

Эта папка содержит краткие фактические итоги завершённых исследовательских шагов.

Назначение папки:

- сохранять промежуточное состояние исследования;
- не смешивать оперативный МАЯК с историей результатов;
- обеспечивать быструю ориентацию при продолжении работы;
- связывать каждый итог с соответствующим этапом дорожной карты и evidence.

## Правило

Промежуточный итог фиксируется только после фактической проверки результата.

Документы этой папки не заменяют подробные evidence и результаты экспериментов. Они содержат краткую контрольную запись о том, что было установлено и какая следующая контрольная точка активна.

## Именование

Рекомендуемый формат:

`WNN_КРАТКОЕ_НАЗВАНИЕ.md`

Каждый новый существенный этап получает отдельную запись.

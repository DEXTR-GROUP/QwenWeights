# W1: получение и проверка Qwen2.5-0.5B Base

## Назначение

Этот этап получает точную ревизию контрольного объекта `Qwen/Qwen2.5-0.5B` и выполняет независимую структурную проверку без использования Transformers.

## Контрольная ревизия

```text
Источник: Qwen/Qwen2.5-0.5B
Ревизия: 060db64
Основной файл: model.safetensors
SHA-256:
88c142557820ccad55bb59756bfcfcf891de9cc6202816bd346445188a0ed342
```

## 1. Получение файлов

В локальном клоне репозитория выполнить:

```bash
python3 tools/prepare_qwen.py ./control/qwen2.5-0.5b
```

Скрипт загружает:

```text
.gitattributes
LICENSE
config.json
generation_config.json
merges.txt
model.safetensors
tokenizer.json
tokenizer_config.json
vocab.json
```

Загрузка выполняется непосредственно из Hugging Face по ревизии `060db64`. `model.safetensors` записывается во временный `.part`-файл и после завершения проверяется по SHA-256.

## 2. Структурная инвентаризация

После успешной загрузки выполнить:

```bash
python3 tools/qwen_inventory.py ./control/qwen2.5-0.5b \
  --output ./reports/qwen2.5-0.5b-inventory.json
```

Инвентаризатор:

- проверяет наличие контрольного набора;
- вычисляет SHA-256 `model.safetensors`;
- читает только заголовок Safetensors до анализа тензоров;
- проверяет JSON-заголовок;
- проверяет границы `data_offsets`;
- проверяет отсутствие перекрытий тензоров;
- считает количество тензоров и параметров;
- фиксирует dtype и shape каждого тензора;
- сопоставляет структуру весов с `config.json`;
- проверяет количество Transformer-слоёв;
- проверяет embedding;
- проверяет Q/K/V/O projection;
- проверяет MLP projection;
- создаёт полный JSON-отчёт.

## 3. Локальные тесты

```bash
python3 -m unittest discover -s tests -v
```

Тесты проверяют независимый разбор заголовка Safetensors, включая корректный файл, перекрытие диапазонов и выход за границы data section.

## 4. Условие закрытия W1

W1 считается закрытым только если одновременно выполнено:

```text
контрольные файлы получены
        AND
SHA-256 совпадает
        AND
Safetensors header корректен
        AND
config.json корректен
        AND
структура tensor names/shapes соответствует config.json
        AND
инвентаризация завершилась W1 PASS
```

До выполнения этих условий никакие утверждения о фактической структуре весов не считаются установленными.

# QwenWeights

## Назначение

`QwenWeights` — отдельное закрытое исследовательское хранилище весов языковых моделей и материалов для их независимого численного исследования.

Репозиторий не является частью `LLAMA-LAB`, `UDEKERNEL`, `NSAI` или другого проекта. Его назначение — исследовать реальные веса как числовую структуру и установить, как они участвуют в вычислительном процессе модели.

Главный исследовательский вопрос:

> Можно ли представить вычислительный механизм реальной языковой модели через минимальный набор прозрачных числовых примитивов и затем воспроизвести его в Rust `no_std`?

## Текущий контрольный объект

**Qwen2.5-0.5B Base** (`Qwen/Qwen2.5-0.5B`).

Выбран как первый объект исследования из-за небольшого размера, открытого доступа к исходным материалам, формата Safetensors и пригодности для поэтапного разбора полноценного Transformer-контура.

Зафиксированная ревизия источника: `060db64`.

Основной файл весов: `model.safetensors`.

Размер файла по источнику: около 988 MB.

SHA-256 файла по источнику:

```text
88c142557820ccad55bb59756bfcfcf891de9cc6202816bd346445188a0ed342
```

Источник: `Qwen/Qwen2.5-0.5B` на Hugging Face. Модель распространяется по Apache 2.0. Точный состав файлов и идентификаторы контрольного набора фиксируются отдельно в `КОНТРОЛЬНЫЙ_НАБОР.md`.

## Принцип разделения

Исследование разделяет:

```text
АРХИТЕКТУРА
    ↓
ВЫЧИСЛИТЕЛЬНЫЕ ОПЕРАЦИИ
    ↓
ВЕСА
    ↓
ПРОМЕЖУТОЧНЫЕ СОСТОЯНИЯ
    ↓
РЕЗУЛЬТАТ
```

Вес не рассматривается как самостоятельная «способность». Он изучается только в связи с конкретным вычислительным контуром и измеряемым результатом.

## Что исследуется

### 1. Числовая структура

- типы чисел;
- диапазоны значений;
- распределения;
- средние значения;
- дисперсии;
- нормы;
- экстремальные значения;
- плотность около нуля;
- различия между слоями и группами параметров.

### 2. Примитивные операции

Исследуется возможность разложения высокоуровневого вычисления на базовые операции:

```text
загрузка
умножение
сложение
накопление
нормализация
нелинейное преобразование
индексация
запись результата
```

Конкретный минимальный набор должен быть установлен экспериментально.

### 3. Чувствительность к весам

Для контролируемых экспериментов могут использоваться изменения вида:

```text
W' = W
W'[i] = 0
```

или масштабирование:

```text
W' = kW
```

Затем измеряется изменение промежуточных значений и конечного результата.

### 4. Воспроизводимость

Для каждого значимого эксперимента должны существовать:

- фиксированный вход;
- фиксированная версия весов;
- фиксированная конфигурация вычисления;
- эталонный результат;
- независимая проверка;
- описание измеряемой величины.

### 5. Перенос в Rust `no_std`

После восстановления конкретного вычислительного участка проверяется возможность его реализации без стандартной библиотеки:

```text
reference
    ↓
primitive numerical form
    ↓
Rust
    ↓
Rust no_std
```

Цель — не сделать преждевременный полный порт модели, а установить минимальные требования конкретного вычислительного участка.

## Что не является целью

- обучение новой модели;
- создание собственного сервиса генерации текста;
- оптимизация ради одного только benchmark-показателя;
- немедленный полный порт всей модели в `no_std`;
- включение весов или результатов этого исследования в другие проекты без отдельного решения;
- утверждения о «смысле» весов без воспроизводимого численного свидетельства;
- заранее выбирать следующую модель до получения достаточного результата по текущему объекту.

## Правило исследования

**Сначала воспроизвести. Затем понять. Затем упростить. Затем оптимизировать.**

Нельзя объявлять вычисление упрощённым, эквивалентным или более эффективным без измерительного подтверждения.

## Связь с внешними проектами

По умолчанию связь отсутствует.

Любая передача результатов в другой проект должна быть отдельным осознанным решением и фиксироваться как новая исследовательская связь.

# LlamaWeights

## Назначение

`LlamaWeights` — отдельное закрытое исследовательское хранилище весов Llama и материалов, необходимых для их независимого численного исследования.

Репозиторий не является частью `LLAMA-LAB`, `UDEKERNEL`, `NS-AI` или другого проекта. Его назначение — исследовать веса как числовую структуру и установить, как они участвуют в вычислительном процессе модели.

Главный исследовательский вопрос:

> Можно ли представить вычислительный механизм, реализуемый реальными весами Llama, через минимальный набор прозрачных числовых примитивов и затем воспроизвести его в Rust `no_std`?

## Принцип разделения

Исследование разделяет:

```text
АРХИТЕКТУРА
    ↓
ВЫЧИСЛИТЕЛЬНЫЕ ОПЕРАЦИИ
    ↓
ВЕСА
    ↓
ПРОМЕЖУТОЧНЫЕ СОСТОЯНИЯ
    ↓
РЕЗУЛЬТАТ
```

Вес не рассматривается как самостоятельная «способность». Он изучается только в связи с конкретным вычислительным контуром и измеряемым результатом.

## Первая исследовательская модель

Первый контрольный набор — **Meta Llama 3.2 1B Base**.

Выбор сделан по инженерному принципу: модель достаточно реальна для исследования полноценного Transformer-контура, но существенно удобнее для поэтапного разбора, контрольных вычислений и последующего переноса отдельных компонентов в `Rust no_std`, чем более крупные варианты.

Официальный источник модели: `meta-llama/Llama-3.2-1B`.

Источник и условия использования должны фиксироваться отдельно от результатов экспериментов. Модель распространяется по Llama 3.2 Community License; при дальнейшем распространении материалов необходимо соблюдать условия лицензии Meta, включая требования к уведомлениям и атрибуции. 

## Что исследуется

### 1. Числовая структура

- типы чисел;
- диапазоны значений;
- распределения;
- средние значения;
- дисперсии;
- нормы;
- экстремальные значения;
- плотность около нуля;
- различия между слоями и группами параметров.

### 2. Примитивные операции

Исследуется возможность разложения высокоуровневого вычисления на базовые операции:

```text
загрузка
умножение
сложение
накопление
нормализация
нелинейное преобразование
индексация
запись результата
```

Конкретный минимальный набор должен быть установлен экспериментально.

### 3. Чувствительность к весам

Для контролируемых экспериментов используются изменения вида:

```text
W' = W
W'[i] = 0
```

или масштабирование:

```text
W' = kW
```

Затем измеряется изменение промежуточных значений и конечного результата.

### 4. Воспроизводимость

Для каждого значимого эксперимента должны существовать:

- фиксированный вход;
- фиксированная версия весов;
- фиксированная конфигурация вычисления;
- эталонный результат;
- независимая проверка;
- описание измеряемой величины.

### 5. Перенос в Rust `no_std`

После восстановления конкретного вычислительного участка проверяется возможность его реализации без стандартной библиотеки:

```text
reference
    ↓
primitive numerical form
    ↓
Rust
    ↓
Rust no_std
```

Цель — не сделать преждевременный полный порт Llama, а установить минимальные требования конкретного вычислительного участка.

## Что не является целью

- обучение новой модели;
- создание собственного сервиса генерации текста;
- оптимизация ради одного только benchmark-показателя;
- немедленный полный порт всей Llama в `no_std`;
- включение весов или результатов этого исследования в другие проекты без отдельного решения;
- утверждения о «смысле» весов без воспроизводимого численного свидетельства.

## Правило исследования

**Сначала воспроизвести. Затем понять. Затем упростить. Затем оптимизировать.**

Нельзя объявлять вычисление упрощённым, эквивалентным или более эффективным без измерительного подтверждения.

## Связь с внешними проектами

По умолчанию связь отсутствует.

Любая передача результатов в другой проект должна быть отдельным осознанным решением и фиксироваться как новая исследовательская связь.

## Текущее состояние

Репозиторий создан как чистая точка старта. Первым контрольным объектом является Meta Llama 3.2 1B Base. Следующий шаг — загрузка и фиксация именно этой версии весов с указанием происхождения и контрольных идентификаторов.
